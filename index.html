Why this exists

The idea

Most weather widgets hide their plumbing. Skyline Ledger keeps it visible: the same extract → validate → clean → aggregate steps a data engineering pipeline runs in production are shown here, stage by stage, on live weather data.

The data source

Readings come from Open-Meteo, a free weather API that needs no key. Geocoding turns a city name into coordinates; the forecast endpoint returns current conditions and a 7-day outlook.

No build step

This is plain HTML, CSS, and JavaScript — no framework, no bundler, no dependency install. That keeps it easy to read, easy to test, and trivial to deploy anywhere that can serve static files.
